# Open Manus App

A simple Flask web application built with Python, HTML, and CSS.  
This project is my first step into web development using Flask.

## Features
- ✅ Home page with styled text
- ✅ About page with navigation
- ✅ Template inheritance (DRY principle)
- ✅ CSS styling with centered layout

## Prerequisites
- Python 3.7+ installed
- pip (Python package manager)
