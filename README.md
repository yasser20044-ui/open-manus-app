# Open Manus App

A simple Flask web application built with Python, HTML, and CSS.  
This project is my first step into web development using Flask.

## Features
- Home page with styled text
- About page with navigation links
- CSS styling for layout and design

## Getting Started

### Prerequisites
- Python 3.x installed
- Flask installed (`pip install flask`)
